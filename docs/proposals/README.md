# Proposals

Significant changes (the pattern schema, the rule format, governance, the network's data rules) start as a written proposal. The process is in `GOVERNANCE.md`: open a GitHub issue labeled `proposal` that links the document here, leave it open for at least 7 days, then a majority of maintainers approves it.

Each proposal says what problem it solves, what it changes, what stays compatible, and what is still undecided. Status is one of `draft`, `accepted`, `rejected` or `superseded`.

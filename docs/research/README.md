# Research

Research notes, scenario designs and results from the Deception and model behavior track, and from any other work that isn't a pattern yet. See [TRACKS.md](../../TRACKS.md).

Each note is one Markdown file named for its topic, with the author, the date, what was tested and on which models, and what is still unknown. Say exactly what was measured and how many times. Early results are welcome when they're labeled as early.

The safety rules in [CONTRIBUTING.md](../../CONTRIBUTING.md) apply here too.
